# Microsoft Fabric Tools Workload - v2026.3

**Release Date:** March 12, 2026

## Overview

March 2026 release of the Microsoft Fabric Tools Workload, introducing the **Cloud Shell Item** - a comprehensive interactive terminal and script management interface for Fabric workspaces. This release also integrates the latest Fabric Extensibility Toolkit updates (v2026.01 and v2026.03) and includes significant improvements to repository sync tooling.

## 🎯 Major Updates

### NEW: Cloud Shell Item 🎉

A powerful new item type that provides an interactive terminal interface for executing Fabric CLI commands and Python scripts through Spark Livy sessions.

**Key Capabilities:**

- **Interactive Terminal**
  - Execute Fabric CLI commands with automatic 'fab' prefix
  - Real-time command execution with output streaming
  - Command history navigation with arrow keys
  - Session context awareness (workspace, lakehouse, environment)

- **Script Management**
  - Create and manage Python (`.py`) and Fabric CLI (`.fab`) scripts
  - Monaco-based code editor with syntax highlighting
  - Full CRUD operations: create, edit, save, delete with protection
  - Organized by categories with folder icons

- **Parameterized Execution**
  - Type-safe parameters: string, int, float, bool, date
  - System parameters automatically available (WORKSPACE_ID, ITEM_NAME, etc.)
  - Two substitution formats for Fabric CLI: `$paramName` and `%paramName%`
  - Spark configuration integration for Python scripts
  - **Variable Picker Integration**: Select workspace variables through native Fabric dialog

- **Batch Job Execution**
  - Run scripts as Spark batch jobs with full monitoring
  - Parameter injection at runtime
  - Job status tracking and log viewing
  - Return value mapping to workspace variables

- **Execution Modes**
  - `FAB_CLI` (Default): Fabric CLI commands with automatic prefix
  - `PYTHON`: Direct Python code execution in Spark
  - `SHELL`: Shell commands via subprocess wrapper

- **Session Management**
  - Automatic Spark session validation and reuse
  - Lakehouse and environment selection
  - Statement execution tracking
  - Session cleanup handling

**Documentation**: Complete architecture and usage guides available in [docs/items/CloudShellItem/](../../items/CloudShellItem/)

## 🚀 Getting Started with Cloud Shell Item

To explore the new Cloud Shell Item:

1. **Create Item**: In Fabric workspace, create a new "Cloud Shell" item
2. **Configure Context**: Select workspace, lakehouse, and environment
3. **Try Interactive Terminal**: Execute `fab workspace list` commands
4. **Create a Script**: Add a new Python or Fabric CLI script
5. **Add Parameters**: Define typed parameters with descriptions
6. **Run as Batch Job**: Execute scripts with monitoring

**Example Workflow**:
```bash
# Interactive terminal
fab workspace list
fab lakehouse list --workspace-id $WORKSPACE_ID

# Create script with parameters
# Python: workspace_analysis.py with parameters (days=7, include_logs=true)
# Execute as batch job with parameter values
```
